Alerta de Proximidad para Personas Ciegas

Proyecto Arduino Uno + Sensor PIR HC-SR501 + Buzzer Pasivo — guía completa de conexión y código

🔩 Componentes necesarios Hardware

🖥️
Arduino Uno (Rev3)
Microcontrolador principal. Cualquier clon compatible también funciona.
📡
Sensor PIR HC-SR501
Detecta calor corporal infrarrojo. Rango ~7 m, ángulo 120°.
🔔
Buzzer Pasivo 5 V
Genera tonos variables con PWM. Más versátil que el buzzer activo.
🔌
Cables Dupont
Macho-macho y macho-hembra para el protoboard.
🧩
Protoboard (mini)
Para montaje sin soldadura. 400 puntos es suficiente.
💡
LED + resistencia 220 Ω
Indicador visual de estado (opcional pero recomendado).

🔗 Esquema de conexiones Cableado

Sensor PIR HC-SR501 → Arduino Uno

Pin PIR Color cable sugerido Pin Arduino Descripción
VCC 🔴 Rojo 5 V Alimentación del sensor
OUT 🟡 Amarillo D2 Señal de detección (HIGH = persona)
GND ⚫ Negro GND Tierra común

Buzzer Pasivo → Arduino Uno

Pin Buzzer Color cable sugerido Pin Arduino Descripción
+ (positivo) 🔴 Rojo D9 Señal PWM para generar tonos
− (negativo) ⚫ Negro GND Tierra común

LED de estado (opcional)

Componente Color cable Pin Arduino Descripción
Ánodo (+) LED 🟢 Verde D13 A través de resistencia 220 Ω
Cátodo (−) LED ⚫ Negro GND Tierra
⚠️
El pin D13 ya tiene un LED integrado en la placa Arduino Uno, por lo que el LED externo es completamente opcional. Si lo usas, siempre incluye la resistencia de 220 Ω para no quemar el LED.

💡
El sensor PIR HC-SR501 tiene dos potenciómetros en la parte trasera: uno para sensibilidad (distancia 3-7 m) y otro para tiempo de retención de la señal (5 s – 5 min). Gíralos según el entorno.

💻 Código Arduino Sketch

pir_buzzer_ciego.ino Arduino IDE 2.x 
/*
 * ============================================================
 *  Proyecto: Alerta para Personas Ciegas - Sensor PIR + Buzzer
 *  Hardware: Arduino Uno + Sensor PIR HC-SR501 + Buzzer Pasivo
 *  Descripción: Detecta personas y emite patrones sonoros
 *               diferenciados para avisar al usuario ciego.
 * ============================================================
 */

// ── Pines ────────────────────────────────────────────────────
const int PIR_PIN    = 2;   // Salida digital del HC-SR501
const int BUZZER_PIN = 9;   // Buzzer pasivo (PWM necesario)
const int LED_PIN    = 13;  // LED de estado integrado en el Uno

// ── Configuración de tiempos (ms) ────────────────────────────
const unsigned long COOLDOWN_MS    = 3000;  // Pausa entre alertas
const unsigned long DETECTION_HOLD = 200;   // Anti-rebote del PIR

// ── Estado global ────────────────────────────────────────────
unsigned long lastAlertTime  = 0;
bool          personaPresente = false;

// ── Prototipos ───────────────────────────────────────────────
void alertaPersona();
void beep(int frecuencia, int duracion, int pausa = 80);
void silencio();

// ─────────────────────────────────────────────────────────────
void setup() {
  pinMode(PIR_PIN,    INPUT);
  pinMode(BUZZER_PIN, OUTPUT);
  pinMode(LED_PIN,    OUTPUT);

  Serial.begin(9600);
  Serial.println(F("Sistema iniciado. Calentando sensor PIR..."));

  // El HC-SR501 necesita ~30 s de estabilización al encender.
  for (int i = 0; i < 30; i++) {
    digitalWrite(LED_PIN, HIGH);
    delay(500);
    digitalWrite(LED_PIN, LOW);
    delay(500);
  }
  Serial.println(F("\nListo. Monitoreando..."));

  // Pitido de confirmación: sistema listo
  beep(1000, 150);
  beep(1500, 150);
  beep(2000, 200);
}

// ─────────────────────────────────────────────────────────────
void loop() {
  int lectura = digitalRead(PIR_PIN);
  unsigned long ahora = millis();

  if (lectura == HIGH) {
    delay(DETECTION_HOLD);          // anti-rebote
    if (digitalRead(PIR_PIN) == HIGH) {

      if (!personaPresente) {
        personaPresente = true;
        Serial.println(F("¡Persona detectada!"));
      }

      if (ahora - lastAlertTime >= COOLDOWN_MS) {
        lastAlertTime = ahora;
        alertaPersona();
      }
    }
  } else {
    if (personaPresente) {
      personaPresente = false;
      Serial.println(F("Zona despejada."));
      digitalWrite(LED_PIN, LOW);
    }
  }
}

// ─────────────────────────────────────────────────────────────
// Patrón: tres pitidos cortos + uno largo (señal universal)
// ─────────────────────────────────────────────────────────────
void alertaPersona() {
  digitalWrite(LED_PIN, HIGH);

  beep(2000, 120, 100);  // pitido 1
  beep(2000, 120, 100);  // pitido 2
  beep(2000, 120, 100);  // pitido 3
  delay(150);
  beep(1200, 500, 0);    // pitido largo (confirma presencia)

  digitalWrite(LED_PIN, LOW);
}

// ─────────────────────────────────────────────────────────────
// frecuencia: Hz | duracion: ms | pausa: ms post-tono
// ─────────────────────────────────────────────────────────────
void beep(int frecuencia, int duracion, int pausa) {
  tone(BUZZER_PIN, frecuencia, duracion);
  delay(duracion);
  noTone(BUZZER_PIN);
  if (pausa > 0) delay(pausa);
}

void silencio() {
  noTone(BUZZER_PIN);
  digitalWrite(LED_PIN, LOW);
}

El cooldown de 3 segundos evita que el buzzer suene sin parar mientras la persona permanece en el rango. Puedes ajustar COOLDOWN_MS en el código según tus necesidades.

🚀 Pasos para cargar el código Guía

  1. Descarga e instala el Arduino IDE 2.x desde arduino.cc/en/software

  2. Conecta el Arduino Uno al PC con el cable USB-B.

  3. Abre el archivo pir_buzzer_ciego.ino con Arduino IDE.

  4. Selecciona la placa: Herramientas → Placa → Arduino Uno

  5. Selecciona el puerto: Herramientas → Puerto → COMx (Windows) o /dev/ttyACM0 (Linux/Mac)

  6. Haz clic en Subir (→). El LED parpadeará 30 segundos mientras el sensor PIR se estabiliza.

  7. Escucharás tres pitidos ascendentes cuando el sistema esté listo para detectar.

  8. Abre el Monitor Serie a 9600 baudios para ver los mensajes de detección en tiempo real.

⚙️ Ajuste del sensor PIR Configuración

🔄
Potenciómetro de sensibilidad (Sx)
Girarlo en sentido horario aumenta el rango de detección (hasta ~7 m). Para interiores, dejarlo a la mitad es ideal.
⏱️
Potenciómetro de tiempo (Tx)
Controla cuánto tiempo la señal OUT permanece en HIGH tras una detección. Ajústalo al mínimo (5 s) para que el código gestione el cooldown.
⚠️
El HC-SR501 necesita 30-60 segundos de calentamiento al encenderse. Durante ese tiempo puede generar falsas detecciones. El código espera esos 30 s antes de monitorear.
